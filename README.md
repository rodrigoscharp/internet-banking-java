# Internet Banking Java

Projeto de internet banking construído com Spring Boot e MySQL.

## Stack

- Java com Spring Boot
- MySQL
- Maven
- HTML, CSS e JavaScript no front-end

## Como rodar

1. Suba o banco de dados com Docker Compose, usando o arquivo compose.yaml.
2. Ajuste as credenciais do MySQL em application.properties.
3. Rode a aplicação com o Maven Wrapper: ./mvnw spring-boot:run
4. Acesse a aplicação em http://localhost:8080
